# CS-465Fullstack

Architecture

The frontend employed a hybrid approach, which leverages both Express, HTML and Javascript for the initial page rendering and a single-page Application, SPA, for dynamic content updates and navigation. The backend utilized a NoSQL MongoDB database for its flexibility and scalability, particularly for handling diverse data structures and rapidly changing application needs. 

Functionality

Json and JavaScript are related but serve different purposes. Javascript is a programming language that provides functionality and interactivity to web applications. It is used for client-side scripting and is capable of performing various tasks. things like manipulating the document object model, also known as DOM, handling user interactions while making AJAX requests. 

Json on the other hand is a data interchange format, that is lightweight, text based format for structured data. JSON is often used to store and exchange data between a server and a client, both front end and back end, in a format that is easy for both humans and machines to read and understand. JSON is a subset of JavaScript's object literal notation but is language-independent and can be used for many programming languages. 

Testing

In a full-stack application, API testing focuses on verifying the functionality,. reliability, performance and security of endpoints which are specific points of interaction for requests and responses between the client and server. Security testing is crucial when it comes to protecting an application against various threats, especially when multiple layers of security are implemented
